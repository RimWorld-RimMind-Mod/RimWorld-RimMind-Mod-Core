[h2]📖 中文介绍 / Chinese Overview[/h2]

  另一边，Bob 刚被救回来。他看到 Alice 独自发抖，

[b]RimMind-Core[/b] 是整个 RimMind 智能体套件的心脏与基础设施。它将大型语言模型（LLM）无缝嵌入 RimWorld 1.6 的游戏循环中，通过高效的上下文编排、异步队列与原生 ToolCall 机制，让殖民地的小人获得真正的思考、记忆与行动能力。

  这不是脚本。不是随机事件表。这是 AI 在那一刻，
  为这两个有性格、有记忆、有情感的小人做出的真实决定。
[h3]🌟 核心特性[/h3]
[list]
[*] [b]4-Zone KV-Cache 深度缓存架构[/b]：创新将系统提示词、角色背景、长期记忆与易变环境（天气/心情/时间）分层解耦，实现高达 [b]80%~90% 的缓存命中率[/b]，大幅降低 API Token 消耗并提升响应速度！
[*] [b]全能模型服务适配[/b]：开箱即用支持 [b]OpenAI (GPT-4o/mini)[/b]、[b]DeepSeek (Chat/Reasoner)[/b]、[b]本地 Ollama / LM Studio / vLLM[/b] 以及 [b]OpenCode Go[/b] 订阅直连。
[*] [b]原生 ToolCall 工具调用体系[/b]：支持复杂嵌套函数调用（Function Calling），AI 不仅能输出台词，更能精准执行游戏内动作。
[*] [b]直观的 F8 智能体调试与控制中心[/b]：按 [b]F8[/b] 随时唤出总控中心，提供实时连通性测试、队列状态、Token 消耗统计、报文检查器与殖民者智能体监控。
[*] [b]统一频率调节滑块[/b]：在设置中提供动态活动频率滑块（0.33x ~ 3.33x），支持从“每3天1次”到“每天10次”的平滑调谐，彻底告别死板定时打卡。
[*] [b]极致性能保护[/b]：网络请求与高开销纯计算全部运行在后台线程，游戏主线程 0 掉帧、0 阻断。
[/list]

[h2]🌐 English Overview[/h2]

  这 Mod 到底好玩在哪？
  ────────────────────
[b]RimMind-Core[/b] is the foundational AI runtime engine for the entire RimMind mod suite in RimWorld 1.6. It bridges large language models (LLMs) with RimWorld's simulation loop, providing intelligent context management, async queue scheduling, and structured tool execution.

  ▸ 小人真的会"想"
    每个 Pawn 都有独立的认知循环：感知→思考→行动→记忆。
    它们会注意到同伴的心情、殖民地的食物短缺、窗外的威胁。
    然后做出自己的判断，甚至形成长期目标。
[h3]🌟 Key Highlights[/h3]
[list]
[*] [b]4-Zone Prompt Caching (KV-Cache)[/b]: Isolates static definitions and pawn profiles from volatile environmental states (time/weather/mood), achieving [b]80%~90% prefix cache hit rate[/b] for massive token cost reduction and lightning-fast responses!
[*] [b]Universal Model Compatibility[/b]: Out-of-the-box support for [b]OpenAI[/b], [b]DeepSeek[/b], local [b]Ollama / LM Studio[/b], and high-speed [b]OpenCode Go[/b].
[*] [b]Unified Native ToolCall Architecture[/b]: Enables structured function calling, allowing LLMs to directly read game states and invoke game mechanics without brittle text parsing.
[*] [b]F8 RimMind Debug Hub & Inspector[/b]: Press [b]F8[/b] in-game to view live AI connectivity, test API ping, inspect token payloads, and monitor colonist agents.
[*] [b]Dynamic Frequency Slider[/b]: Seamlessly scale AI interaction frequency from eco-mode (1 event per 3 days) to active-mode (10+ events per day).
[*] [b]Lag-Free Threading[/b]: All network and compute workloads run on background threads; your RimWorld main thread stays completely butter-smooth.
[/list]

  ▸ 上下文引擎——AI 真正"懂"你的殖民地
    不是把一堆数据丢给 LLM，而是用五层架构精准筛选：
    只给 AI 此刻最相关的信息。BudgetScheduler 控制每次请求
    都在 token 预算内。所以小人不会"失忆"或"胡说八道"。

  ▸ 飞轮自动调优——越用越聪明
    不需要手动调参数。Flywheel 持续监控 AI 响应质量，
    自动调整温度、预算、权重。用得越久，小人越"对味"。

  ▸ 感知桥接——小人不是木头人
    5 个 Patch 把 RimWorld 的原生事件翻译成 AI 能理解的信号。
    受伤、心情崩溃、社交冲突、袭击警报——小人会主动感知，
    不是等你点按钮才反应。

  推荐怎么玩？
  ────────────

  第一步：装 RimMind-Core
    这是引擎。装好，填入你的 API Key，就能跑了。
    支持任何 OpenAI 兼容的 API（OpenAI / 本地 Ollama / 其他）。

  第二步：加 RimMind-Dialogue
    和小人自由对话。这是最直观的体验——直接跟你的殖民者聊天，
    问它们在想什么，听它们抱怨食物难吃。

  第三步：加 RimMind-Personality
    给每个小人分配大五人格特质。内向的科学家、外向的社交达人、
    神经质的艺术家——性格不同，反应完全不同。

  第四步：加 RimMind-Memory
    小人开始记住事情了。三个月前那次袭击，它还记得谁救了它。
    暗记忆系统让 AI 在不知不觉中被过去的经历影响。

  进阶：RimMind-Actions + RimMind-Storyteller
    Actions 让小人自主行动——工作、社交、逃跑，全凭自己判断。
    Storyteller 让 AI 当叙事者，动态生成故事线和事件。
    这两个会让游戏难度和不可预测性大幅上升，建议熟悉基础后再加。

  还有：RimMind-Advisor
    AI 顾问模式。不改变小人行为，而是帮你分析殖民地状况、
    给出建议。适合想用 AI 辅助决策但不想让小人"失控"的玩家。

  常见问题
  ────────

  Q: 贵不贵？
  A: 默认每 500 秒思考一次，token 用量可控。
     用本地 Ollama 的话完全免费。Flywheel 会自动优化避免浪费。

  Q: 和其他 Mod 冲突吗？
  A: 不冲突。RimMind 通过 Harmony Patch 桥接，不修改游戏原生逻辑。

  Q: 可以只装 Core 吗？
  A: 可以跑，但小人只会"想"不会"做"。
     建议至少搭配 Dialogue，体验最完整。

  Q: Player2 模式是什么？
  A: 你自己扮演 NPC 的 AI。适合想亲自"演"角色的玩家。

  给 Mod 开发者

  - 公共 API: RimMindAPI 静态类
  - 注册上下文: ContextKeyRegistry.Register(key, layer, priority, provider, modId)
  - 上下文架构: L0(静态)→L1(基线+Diff)→L2(环境)→L3(状态)→L4(历史)→L5(感知)
  - 请求队列: AIRequestQueue，支持优先级、冷却、取消
  - 详细规范: 见 AGENTS.md
